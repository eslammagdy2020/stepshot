# Testing
- Rewrites acceptance / e2e test files so every test that claims a user workflow actually drives real Qt mouse / keyboard events through `qtbot` — replaces `setSelected(True)`, `setPos(20, 30)`, `set_module_exists`-style symbol checks with synthesized `QMouseEvent` / `QKeyEvent` flows. Each replacement carries a before/after spec rationale. Confidence: 0.9
- Removes symbol-only "this module exists" tests when a behaviour test for the same feature supersedes them — the existence is then implicit in the tool-driven test that imports it. Documents the removal in the phase doc (with the list of test names dropped). Confidence: 0.85
- Pixel-level assertions in acceptance tests: samples pixels via `pixmap.toImage().convertToFormat(QImage.Format.Format_RGBA8888).pixel(x, y)` (with DPR scaling) before/after the operation, asserts the rendered output dimensions, and compares (R,G,B) tuples to prove visual state changed — not just item-count assertions. Confidence: 0.9
- Renames misleading test names to match what the test actually exercises (e.g. `test_unlimited_undo_during_session` → `test_undo_and_redo_around_fifty_state_cap` when the cap is 50). Confidence: 0.85
- Drains stale pytest markers from `pytest.ini` once their last use is gone (e.g. dropping `not_implemented` after all uses are removed), and removes matching `pytest -m "..."` lines from `tests/README.md` and `AGENTS.md` — keeps docs/markers in sync. Confidence: 0.8
- Test-debugging: when a real-mouse synthesis test fails, distinguishes three failure modes — (1) wrong assertion (`pixmap()` returns a copy, use `cacheKey()` for identity), (2) wrong coordinate read (`moveBy` changes `pos()`, not local points; assert `start_point + pos()` for scene-space position), (3) mouse-rounding (allow ±1 px tolerance for synthesized events). Pins each as a separate edit. Confidence: 0.85
- Counts items explicitly when scene order can't be relied on (`scene().items()` doesn't always match insertion order) — uses `sorted(...)` over a property and asserts the multiset, not `[-1]`. Confidence: 0.8
- Tabulates each acceptance test against the spec before rewriting, marking each as OK / Replace / Augment / Remove with a one-line reason per row — then implements the changes in one pass. Confidence: 0.8
- Cross-references bug fixes to the test that catches them via a mutation-check (temporarily revert the fix, confirm the test fails, restore) — proves the test isn't a false negative. Confidence: 0.9
- Verifies type-hint refactors with `typing.get_type_hints(fn)` at runtime, not just mypy — surfaces the difference between real module-level imports and `TYPE_CHECKING`-guarded imports (the latter leave `NameError` for `get_type_hints`). Confidence: 0.85
- Keeps `pytest` suite delta explicit in phase docs: "was N, +M new, now N+M" for every phase close. Confidence: 0.8
